# LipatoS — модули Foundry VTT

Центральный каталог модулей **LipatoS** для Foundry Virtual Tabletop.

Здесь хранится актуальный список модулей, их версии, краткое описание и ссылки на манифесты. При обновлении любого модуля информация в этом репозитории также обновляется.

## Список модулей

| Модуль | Версия | Краткое описание | Манифест |
|---|---:|---|---|
| [LipatoS - Запрет редактирования персонажа](https://github.com/Lipatosha/LipatoS-character-edit-lock) | 1.0.0 | Запрещает обычным игрокам включать режим редактирования карточки персонажа, не ограничивая ГМ и штатное развитие персонажа. | [module.json](https://raw.githubusercontent.com/Lipatosha/LipatoS-character-edit-lock/main/module.json) |
| [LipatoS - Запрет изменения вдохновения](https://github.com/Lipatosha/LipatoS-inspiration-lock) | 1.0.1 | Запрещает обычным игрокам вручную включать и отключать вдохновение, сохраняя стандартный внешний вид кнопки. | [module.json](https://raw.githubusercontent.com/Lipatosha/LipatoS-inspiration-lock/main/module.json) |
| [LipatoS - Расход предметов после броска](https://github.com/Lipatosha/LipatoS-item-after-roll) | 1.0.1 | Списывает заряды и количество предмета только после фактического броска; при отмене броска ресурс не расходуется. | [module.json](https://raw.githubusercontent.com/Lipatosha/LipatoS-item-after-roll/main/module.json) |
| [LipatoS - Запрет изменения зарядов](https://github.com/Lipatosha/LipatoS-item-charges-lock) | 1.0.1 | Запрещает обычным игрокам вручную изменять количество зарядов предметов и показывает подсказку «Количество изменяет только ГМ». | [module.json](https://raw.githubusercontent.com/Lipatosha/LipatoS-item-charges-lock/main/module.json) |
| [LipatoS - Вкладки предметов для игроков](https://github.com/Lipatosha/LipatoS-item-tabs-player) | 1.1.0 | Оставляет игрокам в предметах только вкладки «Описание» и «Функции», скрывает «Подробности» и «Эффекты», а также запрещает редактирование, дублирование и удаление функций. | [module.json](https://raw.githubusercontent.com/Lipatosha/LipatoS-item-tabs-player/main/module.json) |
| [LipatoS — Редактирование биографии игроком](https://github.com/Lipatosha/LipatoS-player-biography-edit) | 1.2.0 | Позволяет игроку включать редактирование только вкладки «Биография», не разблокируя остальные разделы листа персонажа. | [module.json](https://raw.githubusercontent.com/Lipatosha/LipatoS-player-biography-edit/main/module.json) |
